# Infinity Space: o que a V2 vai exigir

Para cada recurso adiado, o que a Infinity precisa providenciar: conta, chave de API, aprovação ou plano pago. Os preços mudam com frequência, então os valores exatos serão conferidos quando a V2 começar. Aqui ficam o tipo de custo e as alternativas gratuitas.

A arquitetura da V1 já deixa os pontos de encaixe prontos; nenhum item abaixo exige refazer o que existe.

## IA

| Recurso | O que precisa | Custo |
|---|---|---|
| **Transcrição de reuniões (pt-BR)** | Opção A, grátis: rodar Whisper (faster-whisper) na própria VPS; exige CPU extra ou uma VPS com GPU para ficar rápido. Opção B: API de transcrição (Deepgram ou AssemblyAI): conta e chave. | A: hardware. B: por minuto de áudio. |
| **Resumo, decisões e tarefas** | Conta na API da Anthropic (Claude) com cartão, chave de API e limite de gasto mensal configurado no painel. | Por uso (tokens). Uma reunião de 1 h custa centavos. |
| **Recepcionista / assistente de IA com corpo** | A mesma chave da Anthropic. Voz opcional pela ElevenLabs (a conta Creator atual já serve para testes). | Por uso. |
| **Legendas e tradução ao vivo** | Transcrição em tempo real (Opção B acima tem modo streaming) + tradução pelo próprio modelo. | Por minuto. |
| **Memória do time** | Banco vetorial: dá para usar o próprio PostgreSQL (extensão pgvector, grátis). Usa as atas da transcrição. | Grátis + uso da API. |

Requisitos de governança (LGPD): aviso visível de gravação e transcrição para todos na sala, consentimento, retenção configurável e política de privacidade atualizada.

## Integrações

| Integração | O que precisa | Custo |
|---|---|---|
| **Google Agenda** | Projeto no Google Cloud com a Calendar API ativada, tela de consentimento OAuth (tipo "interno" se a empresa usa Google Workspace, o que dispensa a revisão do Google), Client ID e secret. | Grátis. |
| **Outlook / Microsoft 365** (se usarem) | Registro de app no Microsoft Entra ID com permissão de calendário. | Grátis. |
| **WhatsApp** (avisos) | WhatsApp Business Platform (Cloud API da Meta): Business Manager verificado, um número dedicado que não esteja em uso no WhatsApp comum e modelos de mensagem aprovados pela Meta. | Por conversa iniciada pela empresa. A aprovação leva dias. |
| **Slack** | App Slack criado no workspace da empresa (bot token). | Grátis. |
| **Discord** | Bot criado no Discord Developer Portal e adicionado ao servidor. | Grátis. |
| **Notion** | Integração interna no Notion (token) e compartilhar as páginas com ela. | Grátis. |
| **ClickUp** | Token pessoal ou app OAuth do ClickUp. | Grátis. |
| **Trello** | Chave e token da API do Trello. | Grátis. |

## Gestão

| Recurso | O que precisa | Custo |
|---|---|---|
| **Gravação de reuniões** | LiveKit Egress (open-source) rodando na VPS + espaço em disco ou um bucket de armazenamento (ex.: Cloudflare R2). Egress usa bastante CPU durante a gravação. | R2 cobra por GB guardado; o egress de saída é grátis no R2. Pode exigir VPS maior. |
| **Convidados externos por link** | Nada externo. Só decisão de política (quem pode convidar, por quanto tempo). | Grátis. |
| **Editor de mapa** | Nada externo. É desenvolvimento. | Grátis. |
| **Relatórios** | Só métricas agregadas e anônimas (uso de salas por horário). Métricas individuais continuam fora, por princípio. | Grátis. |
| **Controle remoto de tela** | Só no app desktop; exige assinatura de código do app no Windows para não ser bloqueado pelo antivírus. | Certificado de assinatura de código: anual. |

## Resumo do que providenciar quando a V2 começar

1. Conta de API da Anthropic com limite de gasto.
2. Projeto no Google Cloud (Calendar API) ou registro no Microsoft Entra.
3. Decidir sobre WhatsApp: se sim, começar cedo a verificação do Business Manager e o número dedicado.
4. Bucket de armazenamento para gravações, se forem gravar.
5. Tokens do Slack, Discord, Notion ou ClickUp, conforme o que o time usa.
