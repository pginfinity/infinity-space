# Infinity Space

O escritório virtual da AI Infinity. Um mundo só, visto em 2D ou em 3D: quem está na planta 2D e quem está no 3D se veem e (a partir da Etapa 1) conversam por proximidade.

## Rodar no seu computador

Precisa de Node.js 24 ou mais novo.

```bash
npm install
npm run dev
```

Abra `http://localhost:5173`. Para testar com duas pessoas, abra uma segunda janela anônima. Na mesma rede, outros computadores e celulares entram pelo endereço "Network" que o terminal mostra.

## Controles

| Ação | 2D | 3D |
|---|---|---|
| Andar | WASD ou setas | WASD (relativo à câmera) |
| Correr | Shift | Shift |
| Ir até um ponto | clique no chão | clique no chão |
| Câmera | arrastar move, rolagem dá zoom | arrastar gira, rolagem aproxima, Q/E giram |
| Trocar de lente | tecla L ou botão 2D/3D | tecla L ou botão 2D/3D |
